# What plunge adds on top of upstream's go.mod files (INTENTIUS/plunge#26).
#
# scripts/plunge-upstream-merge.sh reads this file when an upstream merge conflicts in a go.mod or go.sum.
# It takes upstream's file, re-applies each entry below for that module, and runs `go mod tidy` there.
# Versions are not written here: each entry takes its version (or replace target) from the fork's own
# go.mod on the base branch, so bumping a fork dependency never needs an edit to this file. A require is
# only raised, never lowered: when upstream already requires a newer version, upstream's stays.
#
# One entry per line:
#   <module dir> go                 keep the fork's go directive when it is newer than upstream's
#   <module dir> require <path>     a module plunge itself imports and upstream doesn't require
#   <module dir> replace <path>     a replace plunge adds (none today)
#
# Add a line here whenever plunge adds a direct dependency or a replace to one of these modules. Modules
# that upstream doesn't have (tests/plunge-corpus/*) can't conflict and aren't listed.
